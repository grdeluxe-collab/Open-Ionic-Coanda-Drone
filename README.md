# Open-Ionic-Coanda-Drone
Es un proyecto nacido debate con gémini sobre la posibilidad de que una campana puede eludir la gravedad emitiendo una x frecuencia de sonido. El debate maduro en un prototipo de dron que terminó siendo de pulsos iónicos me deje llevar y salió esto. Los que entiendan del tema sabrán apreciarlo o no.
